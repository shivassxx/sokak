# Sokak Oyunları

Çocukluğun mahalle oyunları, tarayıcıda ve çok oyunculu. İlk mod: **Saklambaç**.

```bash
pnpm install
pnpm dev          # sunucu :2567 + istemci http://localhost:5173
pnpm test         # tüm testler
pnpm build        # üretim derlemesi
pnpm start        # üretim sunucusu (istemciyi de sunar) http://localhost:2567
```
