# Decisions

Decisions taken autonomously on the user's behalf (see CLAUDE.md autonomy rule).

## M0
- **Pinned versions.** Colyseus 0.16 (`@colyseus/core`, `@colyseus/ws-transport`, `@colyseus/schema` 3, `colyseus.js` 0.16), TypeScript 5.9, Vitest 3.2, Vite 7, React 19, Three.js 0.186. Newer majors (Colyseus 0.18, TS 7, Vitest 5) exist but 0.16/5.x are well-known and stable; upgrading is a backlog item.
- **Workspace packages ship TS source** (`exports: ./src/index.ts`). Vite, Vitest and tsx consume them directly; the server is bundled with esbuild for production so no per-package build step is needed.
- **One root Vitest config** runs every package's tests (`pnpm test`).
- **Dev:** `pnpm dev` runs the server (`tsx watch`, port 2567) and the Vite client (port 5173, `--host` so phones on the same Wi-Fi can connect). In dev the client connects to `ws://<page-host>:2567`; in production the server serves the client and the socket on the same origin.

## M1
- **Axis-aligned map only.** Every prop is an AABB so client/server share one cheap collision + raycast routine. Cars face along x or z.
- **Colliders have two flags:** `solid` (blocks movement) and `opaque` (blocks sight). Bushes, tree canopies and laundry sheets are opaque but walk-through → natural hiding spots. Fences and railings are solid but see-through.
- **Movement:** box footprint (r = 0.35 m, h = 1.8 m), step-up 0.5 m (stairs are stacked slabs; you can walk under high steps = "merdiven altı"), jump, crouch (slower, smaller visibility profile). Fixed 50 ms step = one input; identical code on client and server enables prediction + reconciliation.
- **No sprint.** Ebe and hiders have equal speed so the race to base is decided by position, not stamina.
- **Controls:** WASD/arrows, mouse drag to look (double-click = pointer lock), Space jump, C crouch (toggle), E/F "Gördüm!", Tab scoreboard, 1–4 emotes. Touch: dynamic joystick on the left 45 % of the screen, drag-to-look on the right, buttons bottom-right.
- **The 3D bundle is lazy-loaded** (`import('./game/Game')`) so the home screen / lobby shows before Three.js arrives.

## M2
- **Positions are not in the Colyseus schema.** The schema holds only low-frequency data (names, colors, roles, statuses, scores, phase, timer). Positions go out as a per-client `s` message every tick so the server can filter what each client sees (anti-cheat, M4) and include the receiver's own exact body + last processed input for reconciliation. 10 players × ~30 bytes per tick is well within budget.
- **Room ids:** 12 random chars from a 56-symbol alphabet (~70 bits) via `crypto.randomInt`; rooms are private (never matched by `joinOrCreate`).
- **Host** = first human in the room; passes to the next connected human when the host leaves. Only the host can start and add/remove bots. A room with only bots left is emptied (and auto-disposed).
- **Bots** are simulated inside the room (no network), use the same `stepBody`, and are labeled "bot" in the UI and with 🤖 in their name tag.
- **Reconnect:** non-consented leave keeps the slot for 20 s (`allowReconnection`). The client stores `{roomId, reconnectionToken}` in `sessionStorage`, retries automatically on drops and on page reload.
- **Nickname + color** are kept in `sessionStorage` only (no accounts, no persistent personal data). Duplicate names get a number suffix.
- **Vitest runs with `pool: 'threads'`:** Colyseus probes `process.send` (pm2) which breaks Vitest's forks pool.

## M3
- **Phase timings:** Ebe selection 3 s (shows who is Ebe), counting 30 s, seeking 3 min, round-end break 10 s. `SOKAK_TIMERS=fast` (6 s / 45 s / 8 s) exists only for local testing; timings cannot be set by clients.
- **Catch rule:** when the Ebe is inside the base circle every currently spotted hider is sobelendi. Base touches are evaluated every tick, hiders before the Ebe, so a same-tick tie goes to the hider.
- **Herkesi kurtarma** triggers when the last hider still in play (hiding or spotted) reaches the base while at least one player is caught. Everyone caught becomes safe, the saver gets a bonus, and the same Ebe counts next round.
- **Next Ebe:** first caught player of the round; the same Ebe if nobody was caught or after "herkes kurtuldu"; random if the Ebe left or the chosen player left during the break.
- **Scoring:** reach base +3, survive until timeout +2, save everyone +5, Ebe +2 per sobe. Per room only.
- **Summary:** "best hiding spot" = hider unseen the longest, labeled with the named zone where they spent most of their hidden time; "longest survivor" = hider not caught for the longest time.
- **Mid-round joiners** are spectators until the next round (they can walk around but, from M4 on, are invisible to everyone else).
- **Too few players** (< 3 incl. bots) at the end of a break → back to the lobby.

## M4
- **Ranges:** the Ebe receives hider positions up to 34 m when in sight; "Gördüm!" works up to 20 m. Within 1.8 m a hider is always seen (no hiding inside a bush while the Ebe stands in it).
- **No aiming for "Gördüm!":** the server picks the nearest valid hider. One big button is far easier on phones and the server check stays authoritative.
- **"Gördüm!" is refused while the Ebe stands on the base circle.** Otherwise a camping Ebe could spot and catch in the same instant; leaving the base and racing back is the fun part of the real game.
- **Crouching** shrinks the visibility profile (rays to 0.85 m and 0.45 m instead of 1.55/1.0/0.4 m) and halves speed — low walls, cars and bushes become real cover.
- **Hysteresis:** once seen, a hider stays visible to the Ebe for 250 ms to avoid flicker at corners.
- **Bots only use information a player could have:** the Ebe bot sees exactly what the Ebe filter allows; hider bots know where the Ebe is only when they can see it. Bot skill varies (0.6–1.0) so humans can win.

## M5
- **Procedural art instead of downloaded models.** kenney.nl / quaternius.com / polyhaven.com are unreachable from the dev container. Rather than block, every prop is generated from primitives that exactly fill its collider (so visuals can never disagree with collision/visibility), merged by material into a few meshes. This also keeps the download tiny. Recommended CC0 packs are listed in `Docs/ThirdPartyAssets.md`.
- **Streetlights "turning on"** are faked with emissive bulbs, lit windows and additive light pools on the ground (no real point lights → cheap on phones). The dusk value follows round progress: lobby = golden hour, end of seeking = blue hour.
- **Sounds are synthesized** (WebAudio). Turkish voice lines use the device's speech synthesizer only if a Turkish voice exists; otherwise text + SFX only.
- **Quick-chat** stays preset-only (6 phrases from CLAUDE.md + "Hadi ama!"). Chat 1 per 1.2 s, emotes 1 per 0.7 s per player.
- **Mute preference** is stored in `localStorage` (a device setting, not personal data).

## M6
- **Nickname filter** is a small built-in list (no dependency). Strong roots are matched anywhere (even "o.r.o.s.p.u"), short words only as whole words to avoid false positives on common names. Offensive → replaced silently with a random "Adjective Animal" nickname.
- **Analytics** = aggregate counters only, no personal data, no third-party service. `/stats` is public unless `STATS_TOKEN` is set (recommended in production; `.env.example` sets one).
- **Single container** serves the client and the game socket; Caddy only terminates TLS. Simplest possible VDS setup.
- **`pnpm start` uses a `--prod` flag** instead of `NODE_ENV=…` so it also works in Windows shells.
- **Actual deployment is not done** (account-bound: needs a VDS + domain); steps are in `Docs/Deploy.md`.

## M7 — quality pass
- **Characters stay procedural.** The only animated CC0 character reachable (Kenney "Mini Arena" soldier with a helmet) does not fit a children's neighborhood game, so a new, much more detailed chibi kid was built in code (full control over outfits, hats, hair, skin tones; no download).
- **Kenney GitHub starter kits are reachable** (kenney.nl is not): their CC0 pickup trucks and sounds are used. Licenses recorded in ThirdPartyAssets.md.
- **Surface detail via shader, not textures:** a world-space pattern shader keeps the merged-mesh approach (few draw calls) and adds no download.
- **Sprint:** 7.4 m/s vs 5.0 walk, ~3.6 s of stamina, exhausted until 35 % regained. Deterministic in shared physics so prediction still matches the server.
- **Information fairness:** the Ebe only ever gets *directions* (with jitter) for unseen footsteps and pebbles, never positions; hiders only get a 0..1 "Ebe nearness". Crouching is silent.
- **Containers:** one hider per container; invisible to everyone while inside; the Ebe's "Gördüm!" within 1.8 m of the container opens the lid (hider pops out spotted). Hiders can't move inside, and can leave any time.
- **Pebbles:** 12 s cooldown, land at the first obstacle or 11 m ahead; everyone sees the landing, nobody sees the thrower.
- **Vertical speed of remotes is not sent**, so their "airborne" pose is inferred from height changes.

## Mode 2 — 101 Okey in the kahvehane (user request)
- **Scope:** the user asked for 101 Okey as the second game, set in a kahvehane that everybody can enter; friends sit at tables together, winnings buy çay/oralet etc., and tile stealing ("taş çalma") as a fun mechanic. Built as `packages/okey` (pure rules + bot AI, unit tested), `KahvehaneRoom` (public room), kahvehane 3D scene and an HTML okey board.
- **Play money only.** Everyone starts each session with 1.000 ₺ of *virtual* money; nothing can be bought or cashed out, no accounts, nothing is persisted. "Veresiye" gives 200 ₺ to a broke player once every 5 minutes. Child-safety rules stay: no free text (okey-specific preset phrases), nickname filter.
- **Public lobby:** `joinOrCreate('kahvehane')` (max 40 per kahvehane); the invite link `?kahve=<roomId>` puts friends in the same kahvehane. Six tables of 4 seats; empty seats can be filled with bots by the table host.
- **Rules chosen (house rules vary in Turkey):**
  - 106 tiles, gösterge → okey = same colour, next number (13 → 1); 2 sahte okey play as the okey's face; real okeys are wild.
  - Dealer gets 22 tiles and starts by discarding; others 21; 20 left in the deck. Turn passes to the right (seat+1); you may take the top discard of your left player only if you lay it on the table the same turn (otherwise put it back; on timeout the unused tile costs 101).
  - Opening: series melds (runs of one colour, 1 may follow 13; sets of 3–4 colours) worth ≥ 101, or ≥ 5 pairs. After opening: lay more melds (pairs only for pair-openers), işle onto any meld, swap a table okey for the real tile.
  - Scoring per hand (lower is better): finisher −101; others: not opened +202, opened = remaining tile values (okey = 101, pair-openers ×2). Finishing with the okey or "elden" (open and finish in the same turn) doubles everything. Discarding a tile that could be işlenmiş costs +101 (opened players only). Deck running out ends the hand without a finisher.
  - Ace after 13 counts 1 point. No rising opening threshold, no partner play (backlog).
- **Match:** 1/3/5 hands; bet 0/10/50/100/250 ₺ per player into the pot; lowest total wins the pot (split on ties). Turn timer 30 s, then auto-play.
- **Taş çalma (house mechanic):** once per hand, during your turn, swap one of your tiles with the top discard of the player opposite or on your right. Each opponent has a 55 % chance of a private "elleri bir garip" hint and the changed pile is visible to everyone. "Hile var!" within 6 s catches the thief: theft reverted, +101 penalty, 50 ₺ to the catcher. A wrong "Hile var!" costs 20 ₺. Bots occasionally steal and sometimes catch.
- **Orders:** menu (çay 5, oralet 5, Türk kahvesi 12, gazoz 10, ayran 8, simit 7, kaşarlı tost 15 ₺) for yourself, a player or your whole table; the çaycı walks the tray to the table; drinks show as badges at the table.
- **Hidden information:** hands are sent only to their owner; the table view in the schema contains counts, discards, melds and the gösterge only.

## Quality pass 2 — characters, graphics, kıraathane, okey table (user request)
- **Characters use a real rigged CC0 mesh.** Kenney's "Animated Characters" mesh was found in the `pmndrs/market-assets` GitHub repo (CC0, Kenney credited) — GitHub is reachable while kenney.nl is not. The file has a skeleton but no clips, so the existing procedural animation now drives a small virtual joint hierarchy that is mapped onto the bones every frame. The embedded skin texture was dropped; faces, hairlines and outfits are painted on a 512² canvas per look (cached), so the Look customisation (colour, hair, hat, skin) still works and nothing new goes over the wire. Kids use a 0.72 scale and a 1.1× head; the kahvehane uses adult proportions (0.8) and NPC extras (moustache, grey/bald, waistcoat, glasses, tespih).
- **Rendering tiers:** `high` (desktop default) = MSAA + GTAO + bloom + colour grade/vignette; `medium` drops AO; `low` (touch devices) renders directly. The tier steps down automatically when frames stay slow; `?q=low|medium|high` overrides. Shader bump mapping is derived from the same analytic patterns (no textures).
- **Kıraathane look:** 1900s Istanbul-style kıraathane — cement-tile floor (karo), walnut wainscot under sage plaster, Thonet-style bentwood chairs, çini panel behind the ocak, lace café curtains, the evening sun coming through real window openings (the south wall casts shadows), a painted street outside. Regular NPCs (tavla players, a newspaper reader, a dozer, a tea drinker) are decoration only.
- **The okey board is the 3D table.** All tiles are real instanced 3D tiles (one draw call for the whole hall, faces from a canvas atlas): racks with hidden tiles, deck stacks, gösterge, discard piles at each player's right-hand corner, melds in each player's zone. Face-up tiles are laid out in the viewer's frame so numbers read upright; other tables use the south seat as reference. The seated camera is solved so the table sits right above the on-screen ıstaka. Only the player's own rack is HTML (crisp, accessible drag & drop).
- **Rack arranging:** dropping a tile on an occupied slot inserts it and slides the neighbours towards the nearest free slot of that row (like a real ıstaka); a full row swaps. Tap a tile, then tap an empty slot to move without dragging. Drag tracking runs on window pointer events (element capture is lost when tiles re-flow). Rows are 15 slots. A new hand is auto-arranged once ("Seri diz").
- **Less confusing UI:** one contextual instruction line, pulsing hot-spots exactly on the deck / left pile / own pile, per-progress bar ("Per: 87/101"), valid groups outlined green on the rack, the "Elini aç" button only when it would succeed, rare actions (taş çal, geri koy, deste bitti, kalk) in a ⋯ menu, "Hile var!" pops up only after a suspicious-hands hint, a "Nasıl oynanır?" panel.

## Night session — Üsküdar kıraathane and online features (user request, 2026-10-06 night)
- **Bugs reported by the user:** camera jitter while walking (horizontal follow is now exact, only height is smoothed; time-based lerps), bodies stuck in colliders (shared `stepBody` depenetrates along the shallowest axis before sweeping), quick-chat bubbles turning the surroundings black (GTAO halo: bubbles/labels are excluded from AO), walking out of the venue (closed map edges, invisible sea wall, door gaps re-checked). The kahve camera now treats thin walls, the glass storefront and the door header as occluders.
- **Venue:** a *modern* kıraathane as asked (concrete-tile floor, brick wall, oak + black steel, pendant lamps) with 18 hall tables and a 4-table glass-railed terrace (22 tables), still with the çay ocağı and tavla corner. Max 60 players per salon.
- **"Make our small map exactly like Üsküdar":** read as the okey world outside the kıraathane (the user talked about leaving the kıraathane and seeing the sahil). Layout: kıraathane → terrace → street with parked cars → Salacak-style sahil promenade (plane trees, benches, simitçi, çay bahçesi with stools, fishermen, a low stone ledge to sit on) → the sea with Kız Kulesi, a passing vapur, gulls, and the historic peninsula skyline (Ayasofya, Sultanahmet, Topkapı, Süleymaniye, Galata) exaggerated in size so it reads at distance. Üsküdar houses and a hill mosque behind. The Saklambaç mahalle was left unchanged.
- **Market and cigarettes (deviation from the child-safety spirit, explicitly requested):** the bakkal sells virtual items (sigara, su, gazoz, çekirdek, çikolata, dondurma, gazete; the simitçi sells simit/çay/su). Cigarettes are play-money, purely cosmetic (smoke puff animation), carry an on-screen health warning ("Sigara içmek sağlığa zararlıdır. Sadece oyun içi, sanal bir eşyadır.") and give no gameplay advantage. Kept because the user asked for it for an adult kahvehane setting; flagged here so it can be removed with one line in `SHOP_ITEMS` if the audience turns out to be young.
- **Voice chat (deviation from "no voice chat", explicitly requested):** strictly opt-in (off by default, needs a click and microphone permission; listen-only without a mic), peer-to-peer WebRTC so no audio passes through or is stored on the server; the server relays signalling only between two players who both opted in. Groups: the four players of an okey table, otherwise players standing within ~14 m (kept until 18 m; volume falls off with distance). Every player can be muted individually; own mic mute; speaking indicators. Public STUN only; a TURN relay is an account/server task documented in Deploy.md.
- **Lobby system:** `GET /api/salons` lists public salons (named after Üsküdar neighbourhoods) with players/playing/waiting; "Hızlı oyna" seats you at the best table (people already waiting first); "Yeni salon aç" with an optional private flag (hidden from the list, link only — the in-game "Davet et" button shares it); in-salon table list with one-click seating; "Botlarla hemen başla" fills empty seats and deals.
- **Persistent play money without accounts:** an anonymous random device token (localStorage) keys a server-side JSON wallet (balance + last bonus time only; pruned after 60 days). Daily bonus 250 ₺ on the first visit of the day (20 h window). Still no names, no personal data.
- **Levels:** `levelOf(played, won) = 1 + ⌊√((10·played + 25·won) / 40)⌋` with Turkish titles (Çaylak … Efsane). Only finished matches with people count (bots keep no record); stored next to the device wallet; `GET /api/wallet?device=` lets the lobby show the player's own balance/level (the token is the only key).
- **Leaderboard:** online-only — each public salon publishes its five richest present players in room metadata and `GET /api/leaders` merges them. No historical ranking is stored (would need persisting nicknames).
- **NPC paths:** the çaycı plans an A* path on a 0.5 m grid over the kahve colliders (cached, string-pulled) so deliveries to the market, street or sahil never cut through walls.
- **Sahil activities:** feeding the gulls (a simit at the sea → Q throws a piece, the nearest gull dives for it; client-side visual triggered by the normal `used` broadcast) and fishing (rod from the bakkal, 30 ₺, 8 casts). Fishing is server-timed: cast only at the sea, a bite after 3–9 s, 1.7 s to pull, pulling early or late loses the cast, walking > 1.2 m reels in; catches are weighted (istavrit 45, çinekop 25, lüfer 15, palamut 10, an old shoe 5 for the laughs) and announced to the salon. Fish give no money, so fishing can't be farmed against the okey economy.
- **Spectating:** client-only — the public table view is already in the schema, so "İzle" just moves the camera to an empty corner of a running table (tiles oriented for that side, name tags hidden). Leaving: move, E, or the match ends.
- **Göstergeyi göster (added in the night session):** the common 101 house rule — on your own first turn (before your first discard), holding the twin of the gösterge, you may show it once for −101 (recorded as a negative penalty, so it is part of the hand score). Bots always show it.
- **Reload mid-match:** private messages sent before the UI's handlers exist are dropped, so the client sends `resync` once wired and the server re-sends the hand.

## Weekly leaderboard — "Haftanın en iyileri" (2026-10-07)
- **Privacy trade-off (the important one):** until now no nickname was ever stored; the online leaderboard only showed people present right now. A weekly board needs a name next to the score, so the wallet of a device now keeps **the last nickname it finished a match with**. Kept small on purpose: the name is the one already shown to everyone in the salon and has passed the room's nickname filter (offensive names were replaced with a random one at join); it is stored only inside the week stats (`week`/`prevWeek`), so it disappears automatically once it is older than last week (pruned on load and on every save) and the whole wallet still disappears after 60 days unseen. No account, no IP, no other data; device tokens never appear in any response. Only the top 10 are public; your own rank is returned only to the device that asks with its own token.
- **Week:** ISO week (Monday–Sunday) in Europe/Istanbul time (UTC+3 all year), via `Intl` with a fixed +3 h fallback; resets lazily — stats carry their week id, so nothing has to run at midnight and a restart across Monday changes nothing.
- **Ranking:** net winnings from matches (pot share received minus the bet paid), ties → more wins, then fewer matches, then name. Players with negative net are listed too (an honest board; with few players the top 10 may include losses). Tea, shops, missions, bonuses and fines are not counted: the board is about okey.
- **Who counts:** only humans with a device wallet; bots never. **Walking out of a running match** (stand up or disconnect past the reconnect window) counts as a lost match with −bet: otherwise leaving whenever you are behind would keep a perfect record.
- **Last week:** not a separate snapshot — each wallet keeps its previous week's stats until they are two weeks old, so `?week=last` (and the current board's `champion`) is derived and survives restarts; it is final because nobody can add to a past week.
- **Reusable:** `WalletStore.recordMatch(device, name, { won, net })` is game-agnostic (the parallel tavla mode can call it); all modes share one weekly board for now. It needs an existing wallet (created when the device joins), otherwise it returns false.
- **Lobby:** the leaderboard area got two tabs, "🏆 Haftanın en iyileri" (default) and "💰 Şu an en zenginler" (the old online list). The weekly list runs in rank order down two columns (one column under 560 px), highlights your row ("sen"), shows your own rank under the list when you are outside the top 10, and a "👑 Geçen haftanın şampiyonu" line. Refreshed every 30 s.
- **🏆 badge:** cheap enough to include — the player schema got a `trophy` (1–3) field set on join, after each recorded match and on the 2 s meta tick (ranks move when people in other salons finish); it is shown before the name on the 3D name tags and on the okey name plates (also on phones).
## Vapur rides (2026-10-07)
- **One shared timeline.** `packages/shared/src/vapur.ts` `vapurState(timeMs)` gives the vapur's pose and phase from absolute epoch time (cycle 125 s: 30 s docked at the iskele, then 95 s at sea). Server and clients evaluate the same pure function; the client feeds it its server-clock estimate (`Game.serverNow()`, from the snapshot offset), so the drawn boat matches the server. The old client-only caller cycle (and its "away" phase) is gone; the boat is always somewhere visible.
- **Route.** A closed Catmull-Rom loop from the dock: east along the shore, south, west past the tower's south side, round its west side and back north-east to the pier (≈590 m, top speed ≈7.4 m/s, trapezoidal speed profile). The dock's neighbours share its z so the heading at the dock is exactly 0 (no snap when leaving or arriving). The dock moved 0.4 m further out (pier face + 5 m) so the stern never swings into the pier hall. Unit tests check continuity, the docked window, the hull outline staying off the sea wall/pier and ≥32 m from the tower centre (islet).
- **Boarding** happens on the promenade at the pier's sea end (`BOARD_SPOT`, west of the iskele hall, which is a solid building), with "Vapura bin" (E) while docked. Getting off ("İn") is only allowed while docked and puts you back at the boarding spot. A rider who drops is put back there at once (so a reconnect lands on the pier). Riders stay aboard across loops until they get off.
- **On deck you can walk.** Riders keep a deck-local position on the open upper deck (stern deck + the two narrow side walkways, `DECK_AREAS`). The client converts its camera-relative input into the deck frame with the boat's heading before predicting and sending it, so server and client step identically (`stepDeck`) and reconciliation is exact. The camera turns with the boat. Snapshots send riders in deck coordinates (flag bit 3) and every client places them on its own boat, so remote riders do not lag behind the hull by the interpolation delay; the receiver's own deck position rides in `me[8..9]`.
- **On board:** fishing is refused ("kaptan kızar"), tables/benches/quick seat are refused until you get off, the kahve's çaycı cannot deliver to the boat; instead a **vapur çaycısı** (NPC parented to the boat, shop `vapur`: çay, simit, su) sells on the stern deck. Simit from the deck feeds the gulls (counts for the gull mission); every other gull follows the vapur.
- Horn: on casting off and on coming alongside.
- Dev-only `devTeleport` message, registered only when `SOKAK_DEV_TELEPORT=1` (for local browser screenshots); `window.__room` in dev builds.
## Playable tavla (2026-10-07)
- **Rules (`packages/tavla`):** standard backgammon as played in Turkish kahvehanes: 15 checkers each in the usual start position, two dice, doubles play four times, both dice must be played when possible (else the larger one), a hit blot goes to the bar ("kırık") and must enter first, bearing off once all 15 are home with a bigger die allowed from the highest point, win = 1 point, **mars** (the loser bore nothing off) = 2 points; no doubling cube, no backgammon (3×).
- **Opening:** every game of a match starts with the opening roll (one die each, ties re-rolled); the higher die starts and plays both opening dice. (Some kahvehanes let the previous winner start; the opening roll is simpler and fair.)
- **Turn flow:** "Zar at" → move checker by checker (each move uses one die; the server spends the smaller die when two reach the same place) → "Tamam". Moves can be undone within the turn. A turn with nothing to play passes by itself after 1.8 s; once all dice are played it passes after 6 s if the player does not press "Tamam" (keeps the game moving on phones). The 30 s timer auto-plays the turn with the bot.
- **Tables:** four tables in the entrance lounge (x −16.5 / −12.5 / 6.5 / 10.5, z −2.6), two either side of the door, keeping the door lane and the walk between the lounge and the okey rows free. The board's long side runs along x; white (seat 0) sits on the south side. The NPC regulars who used to play there now sit on chairs along the side walls (prayer beads, the paper reader, the dozer).
- **Money and levels:** same wallet and bet options as okey (0/10/50/100/250 ₺ per player); match length 1, 3 or 5 points; the match winner takes the pot (2 × bet). A finished tavla match counts towards `played/won` (levels) and the daily mission, now worded "Bir okey ya da tavla maçı bitir". Standing up mid-match hands the seat to a bot (the bet stays in the pot); a table with no people left closes and the pot is void, as at okey tables.
- **2D board:** shown from the player's side with their home bottom right; the black player's view is mirrored (the physical 3D board has black's home on its left, as at a real table). Point numbers are the viewer's own pip numbers. On landscape phones the board takes the full height and the plates/buttons move to a side column (the HUD is hidden while playing).
- **Bot:** enumerates every legal way to play the roll (deduplicated final positions) and scores them on pip count, hits, made points (home board, anchors, primes), exposed blots weighted by direct/indirect shots, and checkers off; pure races are scored on pips. It beats a random mover at least 15 of 20 games in the unit test — a sane kahvehane opponent, not a strong one.

## 2026-10-07 — Big TV with derbies, staff accounts and admin panel (user request)

- **TV derbies are simulated, not real broadcasts.** Real Süper Lig broadcasts are licensed (pay TV), and the game has no external links, so the TV cannot stream real matches. Staff instead start a *simulated* derby that every salon watches in sync. The match is deterministic from a seed and the kick-off time, with a scoreboard, goals, commentary lines and crowd/NPC reactions. Teams are colour nicknames (Sarı-Kırmızılar, Sarı-Lacivertliler, Siyah-Beyazlılar, …) with no real club names or logos. Shared types: `packages/shared/src/tv.ts`; server channel: `apps/server/src/tv.ts`.
- **Accounts exist for staff only.** Players stay anonymous (nickname + device token), as §3 requires. Staff accounts are username + password, hashed with scrypt and stored in a server-side JSON file. The owner account is `shivass`. Its password comes from `SOKAK_OWNER_PASSWORD`, or a random one is generated and printed once on first start. The owner can create and remove admins and do everything else. Admins can only start and stop TV matches.
- **Admin panel details (implementation):** `SOKAK_OWNER_PASSWORD`, when set, is re-applied at every start (it is the recovery path if the owner forgets the password). A kicked player's device cannot rejoin that salon while it exists (other salons stay open to them). Play-money grants are clamped to ±100 000 ₺ per action and the balance never goes below 0; every staff action is logged with who/what/when. Announcements are owner-only free text (≤140 chars) and still pass the profanity filter. In dev the panel reaches the API through a Vite proxy (same-origin cookie, no CORS), in production it is same-origin behind Caddy.

## 2026-10-07 — Eşli 101 and table settings ("Masa ayarları")
- **Settings** are chosen by the table host in the table lobby, through the existing `tableConfig` message (`TableConfigMsg`): mode Tekli / Eşli, hands 1/3/5/7/9 (default still 1), turn time Hızlı 15 s / Normal 30 s / Yavaş 45 s (default Normal), bet as before. The server ignores invalid values field by field and only accepts them from the host of an open table. The table's turn time scales the room's base timer (`timing.turn × turnSecs / 30`), so tests and `SOKAK_TIMERS=fast` still shorten it. The settings show in the table lobby, the "Masalar" list, the near-table prompt ("eşli") and the in-game info box ("👥 Eşli · Hızlı").
- **Teams:** partners sit opposite each other, seats 0+2 (Mavi takım) and 1+3 (Kırmızı takım). Turn order, dealing, opening (101 / 5 pairs), işleme and the per-seat penalties are unchanged. A team's hand result is the sum of the two partners' scores (`HandResult.teams`).
- **The finisher's partner writes no tile points.** This is the common kahvehane eşli convention. The partner keeps their own fines and bonuses (işlek discard, caught theft, gösterge −101). Opponents pay as in tekli, doubled for an okey or elden finish. If the deck runs out, everyone pays their hand.
- **İşleme onto the partner's melds** is allowed, as onto any meld (no change needed).
- **Taş çalma in eşli:** you cannot steal from your partner's pile (that would just pass tiles inside the team), so only the right-hand opponent's pile is allowed. You cannot accuse your partner ("Eşini ihbar edemezsin."). The partner also gets no "elleri bir garip" hint about their own partner's theft.
- **Money:** the match is won by the lower team total. The pot (4 × bet) is split between the two winners, so each winner gets +bet and each loser −bet. If the team totals tie, everyone gets their bet back. The weekly board and wallets still get each player's own net through `recordWeekly` and level stats. `lastMatch` carries `teams` and `winnerTeams`.
- **Bots in eşli:** the same bot, plus one cheap check: it does not discard a tile the next player (always an opponent) could işle right away when that player has opened with series.
- **Not built (cheap enough to skip):** 3D team colour markers on the table. The HTML name plates over the 3D table already carry the team colours ("🤝 Eş" / "Rakip").
## 2026-10-07 — Graphics quality menu ("Grafik kalitesi")
- **Presets:** Düşük / Orta / Yüksek / Otomatik (default Otomatik), stored in `localStorage` (`sokak.quality`). "FPS göster" (`sokak.showFps`) and the volume (`sokak.volume`) are stored the same way. `?q=low|medium|high` still overrides for dev/tests.
- **Tiers:** Yüksek = pixel ratio ≤1.75, 2048 shadow map over ±30 m, GTAO + bloom + grade, 4× MSAA. Orta = ≤1.5, 1024 map over ±22 m, bloom + grade, 2× MSAA. Düşük = ≤1.25, **no sun shadows**, no post-processing (canvas MSAA, CSS vignette). Tone mapping, exposure and the environment map are the same everywhere.
- **Live vs next load:** pixel ratio, shadows and post-processing change live (no reload). The canvas is always created with `antialias: true`, so no setting needs a context rebuild. What the world builds once (foliage density, the hall's point lamps, strolling NPCs, the preloaded avatar set) follows the tier at load; the panel says so in one line instead of reloading.
- **Otomatik:** starts from a device guess: software GPU (SwiftShader/llvmpipe) → Düşük. Phones → Orta with ≥8 cores, else Düşük. Desktops with ≤4 cores or an Intel/integrated GPU → Orta, else Yüksek. It then measures 1 s windows of real frame time: it steps down after 3 slow windows (<45 fps) in the first ~12 s, or 6 in a row later. It steps up only after 30 s of steady ≥57 fps, and never back to a tier that was already too slow this session (so it cannot flap). A single frame counts at most 0.25 s (tab switches and shader compiles are one hitch, not a trend), and the 2 s after each change are ignored. This replaces PostFX's old step-down-only adapter.
- **Volume:** a 0–100 % slider on the central master gain in `audio.ts`. The existing 🔊 mute button stays. Voice chat has its own per-peer controls and is not affected.
## 2026-10-07 — Real match streams on the TV ("Kanallar", user request)

- **User override:** the owner (`shivass`) said "maçlar gerçek olacak, ben linkini ekleyeceğim". The TV can now show a real stream from a link the owner adds; the owner is responsible for having the rights. This replaces the earlier "simulated only, no external links" decision for the TV. The simulated derby stays as the second option.
- **Channels are owner-only.** A channel is a title (≤60 chars, profanity-filtered, since children see it), an https link (≤500 chars; no credentials, no other scheme, no `javascript:`/`data:`) and a type. Routes: `GET/POST/DELETE /api/admin/channels` (owner; admins get 403). Channels are stored in the staff store's JSON file (`channels` next to `users`), re-validated on load, and every add or remove is in the action log. There are at most 50 channels.
- **Types:** `video` covers direct .mp4/.webm files and HLS .m3u8 streams. `embed` covers every other https page. The type is detected from the path's extension, and the owner can override it. YouTube watch, youtu.be, live, shorts and embed links are normalised to `https://www.youtube-nocookie.com/embed/ID?autoplay=1` and are always `embed`. The shared logic (`normalizeStreamUrl`, `detectStreamType`, `cleanStreamTitle`) lives in `packages/shared/src/tvStream.ts` so the server and the panel agree.
- **Starting a broadcast:** owner or admin. `tv/start` takes `{ channelId }` for a stream or `{ home, away }` for a derby. A request that carries any `url` is rejected with 400, so admins never handle links ("adminler sadece maç açabilir"). `GET /tv` gives admins the channels as id, title and type only. A stream does not expire on its own; staff stop it.
- **`TvBroadcast`** gained `kind: 'sim' | 'stream'` plus `title`, `url`, `streamType` and `channelId`. A missing `kind` means `'sim'`, so old payloads keep working.
- **Client, `video`:** one hidden `<video playsinline crossOrigin="anonymous">`. Safari/iOS play HLS natively; other browsers use the lazy-loaded **hls.js light build** (its own ≈118 KB gzip chunk; the lobby stays at 131 KB). The light build is enough for live football and leaves out subtitles, alternate audio and DRM. One `VideoTexture` is shared by all five TVs, with a "● CANLI · title" strip on top. The sound comes from the big screen: louder as you walk up to it, quiet outside the hall. Following the game's mute, the stream starts muted until the first tap or key because of autoplay rules. If the video errors, taints WebGL (no CORS, probed with a 2×2 canvas readback) or shows nothing for 25 s, the TV falls back to the embed card below.
- **Client, `embed` (and the fallback):** a cross-origin page cannot be drawn into WebGL. The TV shows a "CANLI · title / İzlemek için TV'ye yaklaş / 📺 Maçı izle" card. While a stream is on, the HUD shows a red "📺 Maçı izle" button, which pulses within 11 m of the big screen. It opens a 2D overlay with an iframe (`sandbox="allow-scripts allow-same-origin allow-presentation"`, `allow="autoplay; fullscreen; picture-in-picture"`) or, for `video` links, a `<video controls>`. The overlay has a close button and a "küçült" corner view, and opens as the corner view when the player is seated at a table. The game keeps running underneath. While the overlay is open, the 3D TV is silent so the sound is not doubled.
- **Referrer:** iframes use `referrerpolicy="no-referrer"`. The one exception is the YouTube nocookie embed, which gets `strict-origin-when-cross-origin` (only our origin is sent), because YouTube refuses embeds that send no referrer at all (player error 153).
- **CSP:** neither the app, `index.html` nor the Caddyfile sets a Content-Security-Policy, so there is nothing to widen. `Docs/Deploy.md` lists the directives a future CSP would need.
- **Dev only:** `SOKAK_DEV_STREAM_URL` (+ `SOKAK_DEV_STREAM_TYPE`, `SOKAK_DEV_STREAM_TITLE`) puts a stream on air at startup and skips the https check. It is ignored in production and exists only for local screenshots with a clip served by Vite.

## 2026-10-07 — Day–night cycle over Üsküdar ("gece-gündüz döngüsü")
- **One shared clock, no server state:** `dayTime(serverNowMs)` in `packages/shared/src/dayclock.ts` derives the game hour from absolute time, like the vapur. Epoch 0 is 05:00, and a game day lasts 40 real minutes. The hours are uneven on purpose: dawn 05–07 takes 3 min, day 07–17 takes 9 min, golden hour 17–19:30 takes 10 min, dusk / blue hour 19:30–21 takes 6 min and night 21–05 takes 12 min. So 28 of the 40 minutes are evening or night, the signature look.
- **The original fixed evening is the 18:00–19:00 key**, value for value (sky, sun, fog, hemisphere, exposure, environment, bloom). A unit test pins it.
- **One directional light all day:** it is the sun by day and a low, bluish moonlight at night (the moon sits over the sea, right of Kız Kulesi). A pre-dawn key swings it east gently. Lighting is re-sampled twice a second into preallocated objects, with no per-frame allocation.
- **Night lights are fakes, not lights:** additive floor pools under the hall pendants and the street / sahil lamps (2 instanced draw calls), the emissive lamp/window materials ×1.6, a warm emissive on the storefront glass, an albedo-weighted floodlight emissive on Kız Kulesi's stone (the dark rocks stay dark), an additive "city lights" layer on the skyline (more windows, floodlit mosques and Galata), and stars plus the moon in the sky shader. The hall's existing point lights are unchanged; no new real lights were added.
- **Gameplay touches are client-side and cosmetic:** at night half the gulls and pigeons roost (hidden), the rest fly or peck slower or doze. The simitçi goes home from 22:00 to 06:00: his NPC is hidden and the shop prompt is not offered. The server does not enforce the closing (KahvehaneRoom was being edited by another branch). It is harmless: buying a simit at night via a crafted message gains nothing.
- **Sound:** the game has no crowd bed to make quieter, so the night has crickets (two synthesized WebAudio "singers", faint inside the hall) and three-quarters fewer gull cries.
- **Dev override:** `?saat=21.5` pins the hour in dev builds only. `__game.pinHour(h | null)` does the same from the console. Both are purely visual.
## 2026-10-07 — Seyirci (kibitzer) mode and the end-of-hand replay
- **Seyirci:** anyone standing near a running okey or tavla table can choose "👀 Seyret" (or press E). The server keeps `KPlayer.watch` / `KPlayer.watchTavla`, allows at most **6 spectators per table** (`SPECTATOR_LIMIT`), and puts the spectator at a corner of the okey table (corners first, then a step further out) or at a free end of the tavla board, facing it. Spectators stop watching with "Kalk", by walking away (client: any movement; server: more than the sit reach + 1.4 m from the table), by sitting or boarding the vapur elsewhere, or when the table opens again.
- **Hidden information:** spectators get exactly what every client in the salon already gets: the schema's public table view. Private hands still go only to the seated owner (`KMSG.hand`). While checking this we found that the room-wide `handEnd` okey event also carried **every rack** (`hands: g.hands`). No client used it and the result screen shows scores only, so it was removed: the losers' racks now never leave the server.
- **Kibitzing quick-chat:** three lines were appended to `QUICK_CHAT_OKEY` (indices unchanged): "Ben olsam onu atmazdım…", "Okey sende mi?" and "Bu el bitti sayılır!". Everyone can use them; spectators get them in the read-only board's "💬 Laf at" menu. Their lines show as speech bubbles and next to their names in the "👀 Seyirciler (n)" chip.
- **El sonu tekrarı:** the room keeps a capped log (40) of public moves per hand: deck draws without the tile, takes from the left with the (face-up) tile, discards, opens, melds laid, tiles added, joker swaps and gösterge shows. Thefts are never logged. At hand end, `KMSG.replay` (`HandReplayMsg`) goes only to the humans seated at the table and its spectators. It carries the last 12 moves and the finisher's own melds, which are on the table anyway. If the deck ran out, there are no melds. The client plays it as a ~5 s timeline plus ~2 s of melds fanning out, and it can be skipped.
